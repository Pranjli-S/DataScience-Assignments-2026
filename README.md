## 🏏 Assignment 01: International T20 Cricket EDA
**Folder:** `/Assignment-01`

A comprehensive analysis of international T20 cricket matches, focusing on match outcomes, gender-based trends, and automated scorecard generation.

* **Key Features:**
    * Identified top global venues and frequent head-to-head team matchups.
    * Performed data cleaning on nested JSON-like structures within the dataset.
    * **Scorecard Generator:** A custom-built function that extracts delivery-level data to create a detailed side-by-side batting and bowling summary.
* **Visualizations:** Distribution of win margins, Box Plots (Male vs Female), and Correlation Heatmaps.

## 🌎 Assignment 03: Global Terrorism Analysis (1970-2017)
**Folder:** `/Assignment-03`

An in-depth study of the **United Nations Global Terrorism Analysis (UNGTA)** dataset containing over 180,000 recorded incidents to uncover global security trends.

* **Key Features:**
    * **Temporal Analysis:** Identified the global surge in terrorist activities peaking between 2011 and 2015.
    * **Geographical Hotspots:** Mapped the most affected regions (Middle East, North Africa, South Asia).
    * **Impact Assessment:** Analyzed casualty rates (Killed vs. Wounded) relative to attack types and target categories.
* **Advanced Visualizations:**
    * **Word Cloud:** Identifying high-frequency active terrorist organizations.
    * **Missingno Matrix:** Advanced visualization of dataset sparsity and null values.
    * **Violin Plots:** Visualizing casualty distributions across different global regions.
    * **Crosstab Trends:** Regional attack frequency over decades.
